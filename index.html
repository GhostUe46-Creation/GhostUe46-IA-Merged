    Texto a voz · TTS

    GhostUe46 puede leer sus respuestas con una voz del dispositivo.

    Las voces disponibles dependen de Chrome/Edge y de las voces instaladas en Windows, Android o el dispositivo. Si no hay dos voces españolas instaladas, el sistema intenta diferenciarlas con el tono.

    Generación de imágenes

    Sin Pollinations; se utiliza la herramienta de imágenes de OpenRouter cuando pides explícitamente generar o dibujar una imagen.

    Requiere proveedor OpenRouter, una API key válida y conexión a Internet. La herramienta de imágenes puede tener coste adicional según el modelo utilizado.
